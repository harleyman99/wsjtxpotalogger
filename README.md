FREE OPEN SOURCE FT8-FT4 WSJTX POTA LOGGER

This cross-platform program is written in Python 3.

Begin by opening WSJTX on your computer. 

Open the WSJTX POTA Logger, and as you complete contacts, they will be added to the log.

When you finish your activation, click the export button to create your POTA upload file.

Check the POTA_USER_GUIDE for more information on setting up and using this application.
